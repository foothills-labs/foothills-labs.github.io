What we work on

Three threads, all pointed at the same problem: knowing whether a model's output is correct, and knowing it cheaply enough to iterate.

Evaluation

Benchmarks that check semantic correctness rather than string equality, and that surface failure modes a pass rate hides.

Leaderboards

Reproducible, open scoring pipelines — the harness, the data, and the results published together so a number can be audited.

Agent loops

Automating the experiment cycle: propose a change, run it under a time box, keep it only when the metric moves.

About

Foothills Labs is an independent lab working at the intersection of applied mathematics and machine learning. The through-line across our projects is verification: most interesting model outputs are not exactly matchable against a reference, so the scoring is the research problem.

Everything we can open, we open — harnesses, datasets, and the scripts that produced the numbers. If something here is useful to you, or wrong, please open an issue.
